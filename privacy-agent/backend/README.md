# Privacy Agent Backend

FastAPI planner for the CartNest Privacy Agent. It independently rejects payloads containing
residual personal data, never trusts the extension's gate flag, and defaults to a deterministic
mock planner.

## Run

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Check:

```bash
curl http://127.0.0.1:8000/health
```

## Modes

- `LLM_MODE=mock` (default) — no external calls, no API key.
- `LLM_MODE=openai` + `LLM_API_KEY=...` — OpenAI-compatible chat-completions endpoint.
  `LLM_BASE_URL` and `LLM_MODEL` are configurable.

Set variables in the shell, or copy `env.example` to a private `.env` and load it with your
process manager. The backend does not read the extension's storage. API keys stay server-side.

## Tests

```bash
.venv/bin/python -m pytest -q
```

Tests cover the tripwire, schema validation, mock planning, the full add-to-cart sequence,
sensitive-value planning, prompt-injection resistance, and size limits.

## Safety

- No request bodies are logged. Log lines contain only path, mode, action count and element count.
- Checkout/payment actions are never generated by the mock planner. The extension independently
  blocks them even if an external planner proposes one.
- This local service has no authentication or rate limiting. Do not expose it publicly without
  putting authentication, TLS and rate limiting in front of it.
